## 1. Схема мережі

```
Internet
    │
[R-EDGE]  ← Граничний маршрутизатор (NAT, OSPF, ACL)
    │
[FW-ASA]  ← Міжмережевий екран (зони: outside / inside / dmz)
   / \
  /   \
[DMZ]  [SW-CORE-1]──[SW-CORE-2]   ← Ядро (HSRP, L3, OSPF)
  │          │              │
SRV-WEB  SW-DIST-SALES  SW-DIST-IT  SW-DIST-HR   ← Розподіл
SRV-MAIL      │              │           │
          SW-ACC-SALES  SW-ACC-IT  SW-ACC-HR       ← Доступ
                                   SRV-AD
                                   SRV-FILE
```

### IP-підмережі

| Зона          | Підмережа        | VLAN | Призначення          |
|---------------|------------------|------|----------------------|
| Management    | 10.0.1.0/24      | 10   | Управління пристроями|
| Servers       | 10.0.50.0/24     | 20   | Серверна ферма       |
| Sales         | 10.0.10.0/24     | 30   | Відділ продажів      |
| IT            | 10.0.20.0/24     | 40   | ІТ-відділ            |
| HR            | 10.0.30.0/24     | 50   | Відділ кадрів        |
| Guest WiFi    | 10.0.60.0/24     | 60   | Гостьова мережа      |
| DMZ           | 172.16.0.0/24    | 70   | Публічні сервери     |
| WAN/Transit   | 203.0.113.0/30   | —    | Канал до Internet    |

## 2. Встановлення ПЗ на Parrot OS

### 2.1 Автоматично через setup.sh (рекомендовано)

```bash
# Виконайте з директорії devsec1-main
sudo bash setup.sh
```

Скрипт автоматично встановить на Parrot OS:
- **Python 3** + pip + venv
- **Qt5 залежності** (`python3-pyqt5`, `python3-pyqt5.qtsvg`, `python3-pyqt5.qtwebsockets`)
- **GNS3** (server + GUI через pip3, бо Parrot OS не підтримує Ubuntu PPA)
- **ubridge** (з пакету або збірка з вихідних кодів)
- **qemu-kvm, libvirt, dynamips, vpcs** — емулятори
- **Docker** (для Linux appliances)
- **Python-залежності** (netmiko, pyvis, jinja2, PyYAML)
- **SSH-ключ** `~/.ssh/id_rsa_gns3`

> ⚠️ Після завершення скрипта **обов'язково перезавантажте систему**:
> ```bash
> sudo reboot
> ```

### 2.2 Ручне встановлення (Parrot OS / Debian)

> Parrot OS базується на Debian і **не підтримує** Ubuntu PPA (`ppa:gns3/ppa`).
> GNS3 встановлюється через pip3.

```bash
# 1. Оновлення системи
sudo apt-get update && sudo apt-get upgrade -y

# 2. Qt5 та мережеві залежності (потрібні GNS3 GUI)
sudo apt-get install -y \
    python3 python3-pip python3-venv \
    python3-pyqt5 python3-pyqt5.qtsvg python3-pyqt5.qtwebsockets \
    qemu-kvm libvirt-daemon-system libvirt-clients \
    bridge-utils wireshark dynamips vpcs \
    git curl net-tools

# 3. ubridge — потрібен GNS3 для роботи з мережевими інтерфейсами
sudo apt-get install -y ubridge 2>/dev/null || \
sudo bash -c '
    apt-get install -y libpcap-dev cmake build-essential
    git clone --depth 1 https://github.com/GNS3/ubridge.git /tmp/ubridge
    make -C /tmp/ubridge
    install -m 755 /tmp/ubridge/ubridge /usr/local/bin/ubridge
    setcap cap_net_raw,cap_net_admin+eip /usr/local/bin/ubridge
'

# 4. GNS3 через pip3 (для Parrot/Debian 12+ потрібен --break-system-packages)
pip3 install gns3-server gns3-gui || \
pip3 install --break-system-packages gns3-server gns3-gui

# 5. Додати себе до потрібних груп (потрібен перелогін після цього)
sudo usermod -aG ubridge,libvirt,kvm,wireshark,docker $(whoami)

# 6. Docker
curl -fsSL https://get.docker.com | sudo bash
sudo usermod -aG docker $(whoami)

# 7. Python-залежності проєкту
pip3 install -r requirements.txt || \
pip3 install --break-system-packages -r requirements.txt
```

### 2.3 Запуск GNS3 після встановлення

```bash
# Додати ~/.local/bin до PATH (якщо pip встановив туди)
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

# Запуск
gns3
# Або якщо gns3 не знайдено:
python3 -m gns3
```

## 3. Завантаження образів Cisco

GNS3 потребує образів IOS (`.bin`) або IOSv (`.qcow2`).

### Варіант A — Cisco IOSv (рекомендовано для GNS3)

1. Зайдіть на [GNS3 Marketplace](https://gns3.com/marketplace/appliances)
2. Знайдіть **Cisco IOSv** та **Cisco IOSvL2** (комутатор)
3. Завантажте `.gns3a` (appliance-файл) — він безкоштовний
4. Образи `.qcow2` потрібно отримати через:
   - **Cisco VIRL / CML** (платна підписка)
   - **Cisco DevNet Sandbox** (безкоштовний тимчасовий доступ)
   - Університетська ліцензія

```bash
# Перемістіть образи у стандартну директорію GNS3
mkdir -p ~/GNS3/images/QEMU
mv vios-adventerprisek9-m.vmdk.SPA.157-3.M3.qcow2 ~/GNS3/images/QEMU/
mv vios_l2-adventerprisek9-m.SSA.high_iron_20200929.qcow2 ~/GNS3/images/QEMU/
```

### Варіант B — Cisco IOU (тільки для навчання)

```bash
# Розмістіть iou образ у директорії
mkdir -p ~/GNS3/images/IOU
mv i86bi-linux-l3-adventerprisek9-15.4.1T.bin ~/GNS3/images/IOU/
mv i86bi-linux-l2-adventerprisek9-15.1g.bin ~/GNS3/images/IOU/
chmod +x ~/GNS3/images/IOU/*.bin
```

## 4. Налаштування GNS3 (перший запуск)

```bash
# Запуск на Parrot OS (pip3-встановлення)
gns3
# Якщо "command not found":
export PATH="$HOME/.local/bin:$PATH"
gns3
# Або напряму через python3:
python3 -m gns3
```

**Кроки у GUI:**

1. **Edit → Preferences → QEMU** → вкажіть шлях до qemu: `/usr/bin/qemu-system-x86_64`

2. **Edit → Preferences → IOS on UNIX (IOU)** → завантажте `iourc.txt` з ліцензійним ключем:
   ```
   [license]
   gns3vm = <ваш_ключ>;
   ```

3. **File → Import appliance** → виберіть `.gns3a` файл для кожного апліанса:
   - Cisco IOSv (маршрутизатор)
   - Cisco IOSvL2 (комутатор)
   - (Опціонально) Cisco ASAv (міжмережевий екран)

4. Переконайтеся, що **GNS3 Server** запущено:
   ```bash
   systemctl status gns3-server
   # або запустіть вручну:
   gns3server --daemon
   ```

### 5.1 Створення нового проєкту

1. **File → New blank project** → назва: `MediumCompany`
2. Встановіть розмір canvas: **Edit → Preferences → GNS3 → Grid size: 75px**

### 5.2 Додавання пристроїв

Перетягніть з панелі **Devices**:

| К-сть | Тип апліансу | Ім'я в топології |
|-------|-------------|-----------------|
| 1 | Cisco IOSv (маршрутизатор) | R-EDGE |
| 1 | Cisco ASAv (або IOSv) | FW-ASA |
| 2 | Cisco IOSv (маршрутизатор) | SW-CORE-1, SW-CORE-2 |
| 3 | Cisco IOSvL2 | SW-DIST-SALES, SW-DIST-IT, SW-DIST-HR |
| 3 | Cisco IOSvL2 | SW-ACC-SALES, SW-ACC-IT, SW-ACC-HR |
| 2 | Docker (Alpine Linux) | SRV-WEB, SRV-MAIL |
| 2 | Docker (Alpine Linux) | SRV-AD, SRV-FILE |
| 1 | Cloud (NAT) | Internet |

### 5.3 З'єднання кабелями

Натисніть іконку **кабелю** (або клавішу `C`) і з'єднайте:

```
Internet ──GE0/0── R-EDGE
R-EDGE   ──GE0/1── FW-ASA (outside)
FW-ASA   ──GE0/2── SRV-WEB   (dmz)
FW-ASA   ──GE0/3── SRV-MAIL  (dmz)
FW-ASA   ──GE1/0── SW-CORE-1 (inside)
SW-CORE-1──GE0/1── SW-CORE-2
SW-CORE-1──GE0/2── SW-DIST-SALES
SW-CORE-1──GE0/3── SW-DIST-IT
SW-CORE-2──GE0/2── SW-DIST-HR
SW-DIST-SALES──GE0/1── SW-ACC-SALES
SW-DIST-IT   ──GE0/1── SW-ACC-IT
SW-DIST-HR   ──GE0/1── SW-ACC-HR
SW-ACC-IT    ──GE0/2── SRV-AD
SW-ACC-IT    ──GE0/3── SRV-FILE
```

### 5.4 Налаштування Management мережі (OOB)

Додайте **Cloud** або **Management Network** і підключіть всі пристрої
до VLAN 10 (10.0.1.0/24) через окремий порт управління.

```
Усі пристрої ──Gi_MGMT── [Management Switch] ──── HostPC (10.0.1.254)
```

## 7. Автоматичне розгортання конфігурацій

Після запуску всіх пристроїв у GNS3 використовуйте скрипти з репозиторію:

```bash

# Конфігурації збережуться у configs/<назва_пристрою>.cfg

# Крок 3: Розгорніть конфігурації на всі пристрої
python3 src/deploy_configs.py --inventory inventory.yml

# Крок 4: Розгорніть лише на один пристрій (для перевірки)
python3 src/deploy_configs.py --inventory inventory.yml --device SW-CORE-1

# Крок 5: Згенеруйте ACL
python3 src/acl_generator.py --inventory inventory.yml --apply

# Крок 6: Побудуйте карту топології
```

### 8.1 R-EDGE — Граничний маршрутизатор

```cisco
enable
configure terminal
hostname R-EDGE
no ip domain-lookup
ip domain-name company.local

! SSH v2
crypto key generate rsa modulus 2048
ip ssh version 2
username admin privilege 15 secret Cisco@123!
service password-encryption

! Інтерфейси
interface GigabitEthernet0/0
 description WAN-Internet
 ip address 203.0.113.1 255.255.255.252
 ip nat outside
 no shutdown

interface GigabitEthernet0/1
 description LAN-to-FW-ASA
 ip address 192.168.100.1 255.255.255.252
 ip nat inside
 no shutdown

! NAT — перетворення внутрішніх адрес
access-list 10 permit 10.0.0.0 0.255.255.255
ip nat inside source list 10 interface GigabitEthernet0/0 overload

! Маршрут за замовчуванням
ip route 0.0.0.0 0.0.0.0 203.0.113.2

! OSPF
router ospf 1
 router-id 1.1.1.1
 network 192.168.100.0 0.0.0.3 area 0
 default-information originate

! VTY — тільки SSH
aaa new-model
aaa authentication login default local
line vty 0 15
 transport input ssh
 login authentication default
 exec-timeout 10 0

banner motd ^
*** Авторизований доступ. Всі дії реєструються. R-EDGE ***
^
end
write memory
```

## 11. Типові помилки та вирішення

| Проблема | Причина | Вирішення |
|----------|---------|-----------|
| `sudo ./setup.sh` → "command not found" | sudo скидає PATH або файл не підтягнуто | `git checkout copilot/prepare-evidence-in-gns3 && sudo bash setup.sh` |
| `gns3: command not found` після pip3 | `~/.local/bin` не в PATH | `export PATH="$HOME/.local/bin:$PATH"` потім `gns3` |
| `pip install` → "externally-managed" | Parrot/Debian 12+ захист PEP 668 | Додайте `--break-system-packages` до pip3 |
| GNS3 не запускається | Відсутні права на групи | `sudo usermod -aG ubridge,kvm $(whoami)` + перелогін |
| `ubridge` не знайдено | Пакет відсутній у Parrot repos | `sudo bash -c 'apt install libpcap-dev cmake; git clone https://github.com/GNS3/ubridge /tmp/ub; make -C /tmp/ub; install /tmp/ub/ubridge /usr/local/bin/'` |
| `Permission denied (publickey)` | SSH ключ не додано | `ssh-keygen` та додайте ключ на пристрій |
| `netmiko timeout` | Пристрій недоступний | Перевірте IP та чи запущений пристрій в GNS3 |
| OSPF сусіди не з'являються | Неправильна мережа | `show ip ospf neighbor` + перевірте `network` команди |
| VLAN не маршрутизується | `ip routing` відсутній | `SW-CORE# ip routing` |
| NAT не працює | ACL або binding | `debug ip nat` на R-EDGE |
| Образ не завантажується | Неправильний формат | IOSv потребує `.qcow2`, IOU — `.bin` |
